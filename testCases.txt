## **Testing Methodology:**

### **How to Test Each Case:**
1. **Set up the face expression**: Look at the camera with the specified expression
2. **Enter the text**: Type the exact test case text
3. **Observe the results**: Check:
   - Final emotion decision
   - Weight distribution (text vs face)
   - Masking detection alerts
   - Decision reasoning

### **Expected System Behavior:**
- **Masking Detection**: Should trigger when strong negative text conflicts with neutral/positive face
- **Text Priority**: Should increase with text length and emotional word strength
- **Face Priority**: Should dominate for brief, ambiguous text with clear facial expressions
- **Transparency**: Decision breakdown should clearly explain why each choice was made

### **Key Patterns to Verify:**
✅ **Text dominates when**: Detailed, emotionally strong, contradicts face  
✅ **Face dominates when**: Clear expression, brief/ambiguous text  
✅ **Masking detected when**: "I'm fine" language + negative face, or strong negative text + positive face  
✅ **Balanced when**: Both modalities have moderate confidence and agree

### **Critical Success Indicators:**
1. **Your friend's scenario** (hiding pain with smile) should be correctly identified as sadness
2. **Sarcasm** should be detected as the underlying negative emotion
3. **Minimization language** ("I'm fine") should not be taken at face value
4. **Detailed emotional sharing** should be given appropriate weight
